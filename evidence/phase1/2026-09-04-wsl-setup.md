## 网络边界

- Windows 系统代理和 WinHTTP 代理保持关闭。
- Clash Verge/Mihomo 保持 `mode: global`、`tun.enable: true`，混合端口 `7897`。
- WSL 中 `archive.ubuntu.com` 返回 `198.18.x.x` fake-IP，但 TUN 开启时 HTTPS 返回 HTTP 200，说明 TUN 正常接管。
- Ubuntu 默认 APT 源的 HTTP 请求无法完成；将同一官方源改为 HTTPS 后，`apt-get update` 成功。
- 修改前、修改后的源文件副本位于：
  - `/var/backups/ubuntu.sources.pre-https.codex`
  - `/var/backups/ubuntu.sources.post-https.codex`
- 未修改既有国内招聘直连脚本。Ubuntu/NVIDIA 源继续走全局 TUN，不加入直连排除。

## Linux CUDA 实机验证

使用 `evidence/environment/cuda_smoke.cu`：

```bash
/usr/local/cuda/bin/nvcc -std=c++17 -arch=sm_89 \
  "/mnt/d/Projects/Open-Source Contribution/evidence/environment/cuda_smoke.cu" \
  -o /var/tmp/cuda_smoke_wsl
/var/tmp/cuda_smoke_wsl
/usr/local/cuda/bin/cuobjdump --list-elf /var/tmp/cuda_smoke_wsl
```
